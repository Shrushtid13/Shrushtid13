## 🚀 Featured Projects

### [AutoHeal AI](https://github.com/Shrushtid13/AutoHeal-AI)
Autonomous IT incident remediation platform that detects, classifies, and resolves infrastructure incidents end to end. Combines Kafka-based stream processing, a fine-tuned BERT classifier, and pgvector semantic memory of past resolutions. LLM agents (LangGraph + Llama3/Phi via Ollama) choose between direct fixes, AI reasoning, and fallback strategies — every autonomous action is bounded by Open Policy Agent guardrails and confidence thresholds.
`LangGraph` `Ollama` `BERT` `Kafka` `PostgreSQL + pgvector` `OPA` `FastAPI` `React (TypeScript)` `Docker`

### [SecureExam AI](https://github.com/Shrushtid13/SecureExam-AI)
Full-stack remote exam proctoring platform with real-time face and gaze tracking, a Chrome extension for tab-switch detection, and a candidate session flow that feeds into a scored report — end to end.
`React` `Node.js` `Express.js` `FastAPI` `PostgreSQL` `Redis` `Docker`

### [ActiveLink](https://github.com/Shrushtid13/ActiveLink)
Real-time user presence tracking system with live dashboards, WebSocket-based status updates via Socket.IO, and role-based access control with a real-time approval workflow.
`React (Vite)` `Node.js` `Express.js` `Socket.IO` `Tailwind CSS`

### [Lecture Assistant (Lumina AI)](https://github.com/Shrushtid13/Lecture-Assitant)
Streamlit app that converts audio/video lectures into structured notes with extracted keywords, interactive AI-powered Q&A, and DOCX export.
`Python` `Streamlit` `LLM APIs`
